# Targeted interface corrections

The owner approved targeted improvements to the 0.6.0 interface rather than a new overall design. `home-proposal.png` is the concept shown in the conversation. The functional interface uses independent controls and labels.

Production art:

- `game/assets/polish/mine-portal.png`: isolated industrial mine doorway with an empty sign for the translated runtime label.
- `game/assets/polish/mine-preview.png`: isolated mining assembly used only by the construction drag preview and its catalogue icon. The installed mine artwork is unchanged.

Both assets were generated with the built-in image tool using the concept and the owner's recording as references. Their original generated PNGs are the production files, with alpha preserved.

Portal prompt: extract the single industrial mine entrance from the approved HOME proposal, preserving dark blue beveled metal, cyan lamps, amber work lights, a gold-lit rocky interior and drill; transparent exterior; complete uncropped silhouette; empty upper nameplate; no robot, interface or text.

Preview prompt: isolate one complete mining installation with rocky drill support, conveyor, articulated claw and one fixed wagon; use the actual mine and existing building atlas as visual references; transparent exterior; no surrounding terrain, platform slots, UI, text or rectangular background fragment.
