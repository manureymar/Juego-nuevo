## Diseño compartido

Robot original cian con visor oscuro, ojos cálidos, antena ámbar y un solo cañón lateral. Paneles azul marino, acentos cian y acciones doradas. Barra superior con perfil, vidas, monedas y ajustes. Navegación inferior en el orden SHOP / HOME / LEADERBOARD.

La presentación de batalla existente sigue siendo la apertura del juego. HOME es el menú de campaña posterior.

## Contenido de cada pantalla

HOME: ruta de niveles 10–12, nivel 10 seleccionado, vistas previas de desbloqueos, robot y PLAY.
SHOP: seis paquetes de monedas y tarjeta de misiones para obtener monedas.
LEADERBOARD: filtros MONTHLY / MASTER y GLOBAL / USA, cuenta atrás, podio, lista y posición personal fijada.

Los precios, cantidades de monedas, puntuaciones, jugadores, cuenta atrás, desbloqueos y progresión son ejemplos para visualizar las interfaces. No fijan la economía, los requisitos de desbloqueo ni integraciones comerciales del juego.

Idioma principal inglés; traducciones previstas: SHOP → TIENDA, HOME → INICIO, LEADERBOARD → CLASIFICACIÓN, PLAY → JUGAR.
